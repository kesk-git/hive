# Version 1.31

Version 1.31 puts the fixed list of credential shapes of the design's [Secrets](../../docs/design.md#secrets-hive-keeps-none) section in force. [records.md](../records.md#encoding) states the exact list, fifteen named shapes: six vendor tokens, each a prefix with its exact length and alphabet matched as a whole token run, and nine private-key opening lines, each matched as a whole line, with the matching rules, the field a refusal names and what is not covered by design. The contract library's schema package carries the list. The owner's validation of a body applies it before the first write, and a body holding a string of a listed shape, in a value or a member name, is refused whole, `invalid` with `secret_shape_recognized`, naming the field and the shape and never the text. The journal validates every event against it before any append or repair write and reports that it checks values, so from this version a command's failure detail is kept in the home journal as one diagnostic event of the answering package, with its correlation and the response, its status and its standard error unchanged, none for a replayed or an `ok` answer, and the whole diagnostic dropped when its body holds a listed shape. [events.md](../events.md#diagnostic-events) drops its statement that the journal does not yet apply the check, and the activation clause of [1.28](1.28.md) is met.

It is a minor change by the rule of [spec/README.md](../README.md#changing-a-contract): it activates a refusal that the contract has required since [1.5](1.5.md) and adds no operation, no record kind, no schema, no package and no dependency; no schema changes, since a change to the list changes none; no record written by built code holds a string of a listed shape, so every record, response and declaration those builds wrote is valid under 1.31; and no package declaration or ownership changes, so the library's contract version constant does not move. A later change to the list is a contract change with its own version note.
