# Version 2.11

Version 2.11 records that the workflow named by rule 9 of [Test targets](../test-targets.md#rules-for-every-target) now exists at [`.github/workflows/test.yml`](../../.github/workflows/test.yml). It runs `make test` on GitHub's hosted Windows and Linux runners on pushes to main, nightly at 03:00 UTC and on demand.

The `windows`, `linux` row of [Hive's test contract](../test-targets.md#a-projects-test-contract) is now `built`. The workflow supplies remote test results; the gate's verdict and merge stay on the operator's machine.

No record, request, schema, operation or error code changes. This is a minor change under [Changing a contract](../README.md#changing-a-contract): every request and record valid before the change is valid after it.
