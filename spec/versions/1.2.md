# Version 1.2

Version 1.2, later the same day, commits the schema of the transaction intent, `tx-intent.v1`, which [records.md](../records.md#writing-several-records) requires of every record. It also names `tmp/`, the one directory of each package's own directory that holds the temporary files of writes in progress. It is a minor change: it adds a schema and a directory and changes no record that existed.
