# Version 1.14

Version 1.14 lists the repository's `.no-mistakes.yaml` in the [layout](../layout.md), beside `.claude/settings.json`, as repository configuration for the validation pipeline. The file holds the one fixed gate command: `make check` and then every target whose row in Hive's own [test contract](../test-targets.md#a-projects-test-contract) reads `built`, which are `check`, `test-contract` and `build`, so the command is `make check test-contract build`. No model chooses what runs, and the declared command's result is the test result; a model's verdict on the tests is only a finding.

The gate command is not `make test` whole. `make test` is the check of the finished repository: by [rule 8 of the test targets](../test-targets.md#rules-for-every-target) a target whose package holds no test fails, so `make test` fails for as long as any package target, `test-integration`, `test-distribution` or `check-imports` has nothing to run. The `status` column of Hive's test contract says which targets are built; the change that makes a target built adds it to the command in the same change, and `make test` becomes the gate command when every target is built.

No schema changes. It is a minor change by the rule of [spec/README.md](../README.md#changing-a-contract) and the precedent of 1.12: it changes the prose of the layout and adds no member, no operation, no code, no record kind, no package and no dependency; every record and declaration valid under 1.13 is valid under 1.14; and it asks nothing of code already built, so the library's contract version constant does not move.
