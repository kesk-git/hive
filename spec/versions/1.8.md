# Version 1.8

Version 1.8 renames the parked placement value, Codex in the Void, to `codex-cloud`, in [pool.md](../pool.md) and `records/pool.item.v1`, and states three points the UI review settled: no command offers a short form at a terminal, a decision item is shown in the Pool as a held item among the waiting decisions, and the placement values are labelled Mac, Claude cloud session, By policy and Codex Cloud (parked). It is a minor change by the precedent of 1.5 and 1.7: no build has written a Pool record, and the value was refused by admission in every version, so no record that a build could have written changes; it adds no member, no operation and no code, and asks nothing of built code, so the library's contract version constant does not move; and no stage 1 schema changed.
