# Version 1.29

Version 1.29 defines schema fixtures as accepted files and invalid-case tables with ordered JSON-pointer edits, keeping decoder-refused and byte-sensitive refusals as raw files, in [layout.md](../layout.md#rules) rule 9. It requires the fixture walker to enumerate every committed schema and enforces the exact stage 2 deferrals of [test-targets.md](../test-targets.md#schema-fixture-obligations), each removed in the change that brings its fixtures.

It is a minor change by the rule of [spec/README.md](../README.md#changing-a-contract): it adds no operation, no record kind, no schema, no package and no dependency; every record, response and declaration valid under 1.27 is valid under 1.29; and no package declaration or ownership changes, so the library's contract version constant does not move.
