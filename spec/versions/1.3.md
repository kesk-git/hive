# Version 1.3

Version 1.3, later the same day, commits the schema of the recorded outcome of a mutating request, `request-outcome.v1`, which [records.md](../records.md#schema-notation) requires of every record, and states which responses a caller accepts with a null `request_id`. It is a minor change: it adds a schema and makes explicit a rule the response already stated, and changes no record that existed.
