# Version 2.8

Version 2.8 defines admission's verification of a request's `rule` authority for a sensitive boundary and its rechecking of standing `word` authority. [pool.md's Admission](../pool.md#admission) owns the conditions for both routes.

No schema's shape changes and no operation, member, record or error code is added. This is a minor change under [Changing a contract](../README.md#changing-a-contract): it states a route the contract already named as verifiable, and every request and record valid before the change is valid after it.
