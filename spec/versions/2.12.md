# Version 2.12

Version 2.12 makes the Windows paragraph of [Starting a process](../distribution.md#starting-a-process) say what `contract/exec` builds: the attribute list of the extended startup block carries the job for a non-resident start (`PROC_THREAD_ATTRIBUTE_JOB_LIST`), and the handle list for a plain or resident start or the pseudoconsole for a terminal start. A terminal start's child takes all three of its standard streams from the pseudoconsole, even when Hive's own standard handles are pipes: the start disables handle inheritance and passes no handle list.

No record, request, schema, operation or error code changes. This is a minor change under [Changing a contract](../README.md#changing-a-contract): every request and record valid before the change is valid after it.
