# Version 1.26

Version 1.26 states how the artefact of [distribution.md](../distribution.md#the-artefact) is assembled and what `test-distribution` and `check-imports` are, now that both are built. `make assemble` writes `dist/hive-<version>-<os>-<arch>/` from the seven executables `make build` left in `dist/`, by a Go program of the repository that builds nothing and runs the same on all three platforms. It stamps nothing into an executable: the implementation version is the constant each reports, the source revision is the `vcs.revision` the Go toolchain embeds, which each reports in `capabilities`, and the Go release and platform are read from the build information embedded in each. The assembler refuses to write an artefact whose seven executables differ in version, contract version, source revision or Go release, whose source revision is absent, or whose build information marks the tree as modified; a deliberate development build is not produced at the first stage.

`manifest.json` has the shape [distribution.md](../distribution.md#how-the-artefact-is-assembled) gives, in canonical form: the Hive version, the contract version, the source revision, the Go release, the platform, every regular file except the manifest with its size and digest, and each of the twenty-one links with its target. Its contract version is what the executables report in `capabilities`, the envelope constant, and not the version in [spec/README.md](../README.md); the manifest records what the build reports.

The root `NOTICE` has a form: a fixed header and one block for each import record in `import_id` order, with the record's copyright notices verbatim, or the header and one sentence that no import record exists yet. One function produces it; `check-imports` and the assembler both call it, and the repository's committed file is the function's output.

The rows of [test-targets.md](../test-targets.md#a-projects-test-contract) for `test-distribution` and `check-imports` are now `built`. `test-distribution` declares what it reads in place of `**`: its inputs are every Go file, its own files, the declarations, the embedded schemas, the import records, `LICENSE`, `NOTICE`, the records, the README and the `NOTICE` of the fixture of `check-imports` that its own fixture reads, the artefact and the names of the build files of another toolchain at any depth, so that a later change re-runs it only when it touches one; a changed build file of the repository still affects every test. Its bound stays at 900 seconds, with the reason given there. `check-imports` keeps `**`, since a record names paths anywhere. The seven items of [How it is proved](../distribution.md#how-it-is-proved) are read as that section now says: by headers and build information, by parsing the source, and by running the integration tests under a search path of three directories; the integration tests take the directories of the executables and of the callees from two environment variables the run sets, `HIVE_TEST_EXECUTABLES_DIR` and `HIVE_TEST_CALLEES_DIR`, and fall back to `dist/` and `dist/callee/` otherwise.

It is a minor change by the rule of [spec/README.md](../README.md#changing-a-contract): it adds no operation, no record kind, no schema, no package and no dependency; every record, response and declaration valid under 1.25 is valid under 1.26; and the implementation meets no later contract version than the library's constant states, so that constant does not move.
