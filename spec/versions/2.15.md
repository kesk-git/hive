Version 2.15 corrects one sentence of [Hive's test contract](../test-targets.md#a-projects-test-contract). The paragraph on `test-distribution` stated a figure for the bound of the integration tests it runs, which no longer agreed with the `test-integration` row of the table above it. The paragraph now names that bound by its row instead of by a figure, so the table is the only place the bound is stated.

No record, request, schema, operation or error code changes. This is a minor change under [Changing a contract](../README.md#changing-a-contract): every request and record valid before the change is valid after it. No command, record or home path ownership changes.
