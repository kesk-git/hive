# Version 1.23

Version 1.23 states four points of `hive-fleet provision` that [Creating identities](../identities.md#creating-identities) left to the code, and makes the operation supported: `hive-fleet` answers `provision` and still refuses every other operation as `unsupported`. A name or repository given again for an existing home, workspace or project is returned unchanged with `created` false and nothing updated; a Fleet home's parent home is a fixed attribute, so a different `parent_home_id` for an existing one is a `conflict` with code `already_exists`; a named remote the clone does not have refuses the whole request as `unavailable` with code `source_unreadable`, and a request naming no remote registers origin `none`; a clone path that is not a directory, is outside a Git repository or is in a bare repository is refused the same way, and a Git too old for the options used is `unavailable` with code `dependency_unusable`.

No schema changes. It is a minor change by the rule of [spec/README.md](../README.md#changing-a-contract): it adds no member, no operation, no record kind, no package and no dependency; every record and declaration valid under 1.22 is valid under 1.23; and the implementation meets no later contract version than the library's constant states, so that constant does not move.
