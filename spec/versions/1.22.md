# Version 1.22

Version 1.22 makes `test-synapse` and `test-ui` built targets. The `synapse` and `ui` packages each have their executable, `hive-synapse` and `hive-ui`, which acts as the command name it was started under: all three names of `synapse` and the one of `ui` answer `capabilities` and refuse every other operation as the [command contract](../commands.md) states, and each package's target holds its first tests. The rows of [Hive's test contract](../test-targets.md#a-projects-test-contract) for the two targets read `built`, and the fixed gate command of `.no-mistakes.yaml` adds them, by the rule of [version 1.14](1.14.md) that the change that makes a target built adds it in the same change.

No schema changes. It is a minor change by the rule of [spec/README.md](../README.md#changing-a-contract): it changes the status of two rows and the gate command, and adds no member, no operation, no record kind, no package and no dependency; every record and declaration valid under 1.21 is valid under 1.22; and it asks nothing of code already built, so the library's contract version constant does not move.
