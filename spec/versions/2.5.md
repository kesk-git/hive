# Version 2.5

Version 2.5 corrects the rule "Keyed on the original" in [commands.md](../commands.md#a-command-with-no-store) to the rule [word.md](../word.md#how-word-persists-through-the-pool) already states.
The callee's harness treats a request as a handoff when its caller names a package that declares no home path and the command of that package the executable lists, and its causation is a `hive.request` of its own `request_id` with a `digest`.
A request that names the package and another command is keyed on its own digest, as every other request is, and is no longer answered with the outcome recorded of the handoff.
An executable declares each handoff by package and command, and the declaration agreement refuses a listed handoff whose command its package does not declare.

This is a minor change under [Changing a contract](../README.md#changing-a-contract): it brings commands.md into line with what word.md already requires and changes no record, schema or ownership.
