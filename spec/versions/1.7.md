# Version 1.7

Version 1.7 names the Wave as the fourth level of the design's work hierarchy, an ordered group of Targets recorded as grouping data on each of its Targets with no Pool item of its own, and states the design's schedule rule in the Pool contract: a schedule belongs to a Hunt or to a Prey that is a single Hunt, never to a Target or to a Prey that holds Hunts, so `add` refuses a Target with a schedule, `update` refuses a schedule set on either, and the conversion of an item to a Target and the first Hunt beneath a Prey are refused with `pool.hierarchy` while the item carries one. It is a minor change: it adds no member, no operation and no code, and asks nothing of built code, so the library's contract version constant does not move; every record and declaration valid under 1.6 is valid under 1.7 but a Target that carried a schedule, which the design never allowed and no build has written, and no stage 1 schema changed.
