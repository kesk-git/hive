# Version 1.24

Version 1.24 makes `test-integration` a built target. Its tests under `integration/calls/` start the seven executables that `make build` leaves in `dist/`, each under every command name of its package, and the test-only callee under `integration/testcmd/`, which the target builds from Go into `dist/callee/` before the tests start, always through the one process-execution path. The target starts the tests with `dist/` and `dist/callee/` ahead of the rest of the search path, written in the platform's own list syntax, so that the one process-execution path reads them when it is loaded and finds every program by name, as it would for a real installation; no test changes the search path or reaches into the library for it, and a test fails, saying what to run, when a program found by name is not the built one. They prove every call of the [calls between packages](../packages.md#calls-between-packages) through the real command line, up to the refusal the contract states for an operation declared and not built, and prove the request and response envelopes, each exit state, replay and a record of 2,097,152 bytes crossing whole or failing with `too_large` and no partial result against the test-only callee, as the row of [the test targets](../test-targets.md#the-targets) states.

The row of [Hive's test contract](../test-targets.md#a-projects-test-contract) for `test-integration` is measured: class `check`, since the target finishes well within its bound and needs nothing beyond the machine; the bound 120 seconds; the status `built`; and `reads` no longer `**` but the sources and declarations the executables are built from (`packages/**`, `contract/**` and `spec/**`), the executables themselves (`dist/hive-*`), and the tests and the callee (`integration/calls/**` and `integration/testcmd/**`); the callee's built directory `dist/callee/` is no input of its own, since the target rebuilds it from the callee's source each time it runs. A change to a build file still affects it, by the first rule of that section. The gate command of `.no-mistakes.yaml` is not changed by this version.

No schema changes. It is a minor change by the rule of [spec/README.md](../README.md#changing-a-contract): it changes the status, class, bound and inputs of one row, and adds no member, no operation, no record kind, no package and no dependency; every record and declaration valid under 1.23 is valid under 1.24; and it asks nothing of code already built, so the library's contract version constant does not move.
