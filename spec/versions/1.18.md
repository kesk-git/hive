# Version 1.18

Version 1.18 lets a transaction carry no outcome. A mutation that must record its intent and its receipts before an effect outside Hive commits them as one transaction that writes its records and receipts and removes its own intent, and leaves `requests/<request_id>.json` unwritten, so that the request stays open and an outcome that proves unknown is never recorded as complete, as [commands.md](../commands.md#exit-and-error-states) states. [records.md](../records.md#writing-several-records) says that the outcome is written when the transaction carries one, and the `outcome` member of [`tx-intent.v1`](../schemas/tx-intent.v1.schema.json) is optional.

It is a minor change by the rule of [spec/README.md](../README.md#changing-a-contract): a member becomes optional, so every intent valid under 1.17 is valid under 1.18, and a transaction that carries an outcome is written exactly as before. No earlier writer wrote an intent without the member. The library's contract version constant does not move.

Version 1.18 also states five points of [the one process-execution path](../distribution.md#the-one-process-execution-path) that the contract had left to the code, now that the path is built. A program's name is a bare word with no extension on every platform: on Windows the run appends `.exe`, a name that ends in `.exe` in any case is refused as not a bare name, and a project that runs `cmd.exe` declares `cmd`. A Windows command line is refused above 32,766 UTF-16 code units, so that with its terminating NUL it fits the 32,767 characters `CreateProcessW` takes. A run that breaks the rules on arguments, the program's name, the working directory or the streams is `failed` with code `internal`. A Hive command reached through its link in `bin/` that is not found or not executable is `unavailable` with `dependency_missing` or `dependency_unusable`. The scan that no other package starts a process covers every non-test Go file outside `contract/exec`, since the rule holds the code Hive delivers and not its tests, as the `test-contract` row of [test-targets.md](../test-targets.md#the-targets) says. These add no member, no operation and no code, and no program built before this version depends on them.
