# Version 2.13

Version 2.13 makes rule 9 of [Test targets](../test-targets.md#rules-for-every-target) state how the hosted Windows workflow runs `make test`: through WMI's `Win32_Process.Create`, outside the runner's job, with its output and exit status reported as the step's. This lets the unchanged resident tests prove a real resident start and survival after its starter ends in the declared Windows test environment.

No record, request, schema, operation or error code changes. This is a minor change under [Changing a contract](../README.md#changing-a-contract): every request and record valid before the change is valid after it.
