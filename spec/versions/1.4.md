# Version 1.4

Version 1.4, later the same day, adds the stage 2 contracts: the Pool's eight records, twenty-seven operations, twenty-five receipt kinds, seventeen event kinds and six identifier prefixes, in [pool.md](../pool.md) and the schemas it names, with the `pool` declaration amended. It is a minor change: every record, request and declaration valid under 1.3 is valid under 1.4, and no stage 1 schema changed.
