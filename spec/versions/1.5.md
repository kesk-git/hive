# Version 1.5

Version 1.5, later the same day, makes the amendments the design's [Secrets](../../docs/design.md#secrets-hive-keeps-none) section needed of these contracts: the owner's no-value check before the first byte of any write, the error code `secret_shape_recognized` and the five codes of the platform's secret store and its utility, the identifier prefix `spoor_`, the calls from `dispatch` to `word` and from `synapse` to `dispatch` and the platform utility `security`, each declared in the two packages' own declarations in the same change, a fifth kind of program a Hive executable may run, a platform utility it declares, with the operation's own `platform` member in the capability declaration, whose `schema_version` advances to 1.1 and still accepts 1.0, and the clause that the only way a resolved value enters a child process is the one variable Tendril sets. It also amends in place the Pool's definition of a secret reference, `secret_ref` of `records/pool.item.v1`, so that it holds one member, the `spoor_` identifier of a Spoor, and nothing else, with the identifier's definition `spoor_id` added to the common schema; its consumers, the Imperative record's allowed credentials and the create and revise requests of `hive-imperative`, follow without a shape of their own. No build has written a Pool record and no lane of stage 2 has started, so this is an amendment of a definition not yet built, inside this contract version: no second schema file and no migration is added. It is a minor change: it adds a code, a call, a prefix and a clause, and changes no record that existed.
