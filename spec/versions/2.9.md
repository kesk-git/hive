# Version 2.9

Version 2.9 states the refusal of a close of a generation that cannot be closed. `hive-pool close-generation` refuses a generation that the item does not have, or one that is not open, with `pool.generation_not_open`, the code `hive-imperative deliver` already uses for the same condition. The refusal's detail for a delivery names the item and the generation; the close refusal carries no such detail.

No schema's shape changes and no operation, member, record or error code is added. This is a minor change under [Changing a contract](../README.md#changing-a-contract): it states the code of a refusal the error table named only for a delivery, and every request and record valid before the change is valid after it.
