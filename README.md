# Hive

A supervisor for Claude Code and Codex agents: an operator's firstmate that keeps every capability of the original on the Mac and adds cloud sessions as an option, never a limit.

Vocabulary, from the Tyranids of Warhammer 40,000: the operator is the Hive Mind; the supervisor is the Hive; each project's persistent supervisor is a Hive Fleet named after its project; workers are Swarms; investigators are Lictors; the review gate is Synapse; a brief is an Imperative; the backlog is the Pool; a pull request is a Harvest; a merge is Assimilation; the cloud is the Void; supervision is the Shadow in the Warp.

Research and development of Hive is carried out by a dedicated second mate of the operator's current fleet, which may read the original firstmate at https://github.com/kunchenguid/firstmate.
